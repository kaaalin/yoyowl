# YoYo Merchant Migration prototype

Vercel-ready Next.js package of the Worldline and Genesys campaign prototype.

## Deploy on Vercel

1. Extract this ZIP.
2. Upload the extracted folder to a GitHub repository.
3. In Vercel, choose **Add New > Project** and import that repository.
4. Keep the detected framework as **Next.js** and select **Deploy**.

No environment variables are required for this frontend prototype.

## Run locally

```bash
npm install
npm run dev
```
